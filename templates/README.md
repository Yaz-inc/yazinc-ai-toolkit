# Templates

Copy-paste starters for new projects. Generalized — no client names or secrets.

| File | Skill | Usage |
|------|-------|-------|
| [fix.php.example](fix.php.example) | `laravel-deploy-fix-php` | `cp templates/fix.php.example public/fix.php` on each server |
| [push-both-repos.example.ps1](push-both-repos.example.ps1) | `laravel-dual-repo-push` | Copy to project `scripts/`, set repo URLs |
| [TracksSoftDeletes.php.example](TracksSoftDeletes.php.example) | `laravel-soft-delete-trash` | Copy to `app/Traits/` |
| [form-field-heights.css.example](form-field-heights.css.example) | `laravel-form-select2-global` | Merge into layout `styles.blade.php` |

See [WORKFLOW.md](../WORKFLOW.md) when promoting new templates from a finished project.
